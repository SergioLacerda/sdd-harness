# `.sdd/trust/` — signing keyring

This directory holds the Ed25519 keypair(s) used to sign local governance
artifacts and the public keyring that the runtime trusts when verifying them.

## `dev-01.key` / `dev-01.pub.pem`

`dev-01` is a **local development / test-only signing key**, generated by
`sdd governance keygen` during bootstrap. It exists so a single developer
workstation can sign and verify compiled governance artifacts without a
shared production signing service.

- `dev-01.key` (the private key) is **never committed** — it is excluded via
  `.gitignore` (`.sdd/trust/*`, with `trusted-keys.json` re-included as the
  only tracked file). Only its public counterpart is trusted by the runtime.
- If `dev-01.key` is ever exposed (committed, leaked, copied off this
  machine), treat it as compromised: delete it, run
  `sdd governance keygen` to generate a fresh key, remove the old `dev-01`
  entry from `trusted-keys.json`, and re-sign artifacts.
- `strict`/production signature verification (`SDD_SIGNATURE_MODE=strict`)
  must not rely on a `dev-*` key. Production and CI signing should use a
  dedicated, non-dev keyring provisioned outside this workspace.
