# 🏗️ RULESET — Project Structure

## 🎯 Purpose

Ensure predictable and scalable architecture.

---

## 🔒 HARD RULES

- MUST follow framework conventions:
  - Rails / Django / Next.js / etc.

- Modules MUST be:
  - small
  - focused

---

## 🟡 SOFT RULES

- Structure SHOULD be predictable:
  - controller / model / view
  - src / lib / test

---

## ❌ ANTI-PATTERNS

- god files
- mixed responsibilities
