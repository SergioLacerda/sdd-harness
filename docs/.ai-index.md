## 🛠️ CLI Command Reference

### Testing

```bash
sdd test run                     # all tests
sdd test run --fail-fast         # stop on first failure
sdd test run --verbose           # detailed output
```

### Governance

```bash
sdd governance compile           # compile specs → generated/
sdd governance validate          # verify fingerprints / integrity
sdd governance generate          # regenerate agent seed files (CLAUDE.md etc.)
```

### Runtime

```bash
sdd runtime status               # workspace health check
sdd doctor run --mode real       # full diagnostics
sdd ask-full ask-full "<question>"  # query governance context
```

### Lint

```bash
sdd lint run                     # ruff + black + mypy
```

### Project Setup (client side)

```bash
sdd init                         # populate .spec.config in a client project
cat .spec.config                 # shows spec_path pointing to this repo
```

### Core Architecture

```

packages/core/sdd_telemetry/     ← Telemetry layer

packages/features/sdd_wizard/    ← Setup wizard (logic)
packages/interfaces/sdd_cli/     ← CLI entry point (sdd command)
packages/interfaces/sdd_wizard/  ← Wizard UI / interactive flows
```
