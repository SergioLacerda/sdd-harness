# `.sdd/` Folder Reference

The `.sdd/` directory at the repository root is the **runtime governance state** for SDD Harness. It contains compiled governance artifacts, skill definitions, CLI command routing, IDE seed files, and cryptographic keys.

---

## What is committed vs. gitignored

The `.gitignore` rules for `.sdd/` are deliberately selective:

```
.sdd/*                                   # ignore everything by default
!.sdd/compiled/                          # EXCEPT compiled artifacts dir
.sdd/compiled/*                          # ignore its contents
!.sdd/compiled/governance-core.json.sig  # EXCEPT signatures (committed)
!.sdd/compiled/governance-client.json.sig
!.sdd/trust/                             # EXCEPT trust directory
.sdd/trust/*                             # ignore its contents
!.sdd/trust/trusted-keys.json            # EXCEPT the public keyring
```

**Committed to git:**
- `.sdd/compiled/*.sig` — cryptographic signatures for governance artifacts
- `.sdd/trust/trusted-keys.json` — public keyring for signature verification
- `.sdd/skills/`, `.sdd/commands/` — skill and command definitions
- `.sdd/seedlings/` — IDE agent seed files
- `.sdd/templates/` — YAML templates for skills and commands
- `.sdd/agent-instructions.md` — agent bootstrap instructions
- `.sdd/metadata.json` — workspace version and mandate fingerprints
- `.sdd/source/` — governance source (mandates, compiled JSON)

**Gitignored (runtime state, regenerated):**
- `.sdd/compiled/*.json`, `*.msgpack` — compiled artifacts (regenerated by `sdd governance compile`)
- `.sdd/runtime/` — ephemeral session state, telemetry, compliance events
- `.sdd/trust/dev-*.key`, `*.pub.pem` — private keys (never commit private keys)
- `.sdd/profile` — active profile cache

## Directory Structure

```
.sdd/
├── agent-instructions.md        # START HERE — agent bootstrap instructions
├── metadata.json                # workspace version + mandate fingerprints
│
├── source/                      # Source of truth for agent pre-caching
│   ├── governance-core.json     # All mandates (machine-readable)
│   ├── governance-client.json   # Client-side governance rules
│   └── mandates/
│       └── mandates.md          # Human-readable mandate descriptions
│
├── compiled/                    # Signed governance artifacts (partial commit)
│   ├── governance-core.json.sig         # Ed25519 signature
│   ├── governance-client.json.sig
│   ├── governance-core.compiled.msgpack # Binary artifact (gitignored)
│   └── audit/                           # Deployment manifests
│
├── skills/                      # Registered skill definitions
│   ├── registry.json            # Skill registry index
│   └── <skill-name>/
│       └── skill.yaml           # Skill contract
│
├── commands/                    # CLI command routing
│   ├── registry.json            # Command routing config
│   └── <command-name>/
│       └── command.yaml         # Command definition
│
├── seedlings/                   # IDE integration seeds
│   ├── vscode.seed.json         # VSCode agent configuration
│   ├── cursor.seed.json         # Cursor IDE configuration
│   └── agent-prep.seed.json     # Generic agent preparation
│
├── templates/                   # Generation templates
│   ├── skill/skill.yaml.tpl
│   └── command/command.yaml.tpl
│
├── trust/                       # Cryptographic keys
│   ├── trusted-keys.json        # Public keyring (committed)
│   └── dev-01.pub.pem           # Public key (committed)
│   # dev-01.key is gitignored — never commit private keys
│
└── runtime/                     # Ephemeral session state (gitignored)
    ├── compliance-events.jsonl  # Append-only compliance log
    ├── bootstrap-state.json     # Phase marker
    └── .sdd-cache.md            # Agent context cache hint
```

## Common Operations

| Goal | Command |
|---|---|
| Regenerate compiled artifacts | `sdd governance compile` |
| Verify artifact integrity | `sdd governance validate` |
| Regenerate skill/command files | `sdd skills full-bootstrap` |
| Check runtime state | `sdd runtime status --force` |
| Generate IDE seeds | `sdd governance generate --full-bootstrap` |
