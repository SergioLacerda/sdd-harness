# ADR-013: CLAUDE.md as Pointer, Not Snapshot

- Status: Accepted
- Date: 2026-05-20

## Context

`CLAUDE.md` is read by agents at workspace bootstrap. It can be structured in two ways:

**Snapshot:** `CLAUDE.md` contains the governance rules directly — mandate summaries,
command listings, skill descriptions, and behavioral constraints are written inline.

**Pointer:** `CLAUDE.md` contains only an entrypoint contract and a precedence rule,
delegating all authority to `.sdd/agent-instructions.md` (the compiled governance artifact).

The choice matters because `CLAUDE.md` is a static file while `.sdd/agent-instructions.md`
is regenerated by `sdd governance compile`. A snapshot diverges silently whenever governance
is recompiled without also updating `CLAUDE.md`.

## Decision

`CLAUDE.md` is a **pointer**. It contains:

1. An entrypoint contract (which files to load on startup)
2. A precedence rule: if `CLAUDE.md` and `.sdd/agent-instructions.md` conflict,
   `.sdd/agent-instructions.md` wins

It does not contain mandate text, skill definitions, command listings, or any content
that originates from compiled governance artifacts.

## Consequences

**Positive:**

- Zero drift between `CLAUDE.md` and compiled governance — they cannot diverge
- Single source of truth: all behavioral rules live in `.sdd/`
- `CLAUDE.md` never becomes stale after `sdd governance compile`
- Reduces maintenance overhead: governance updates do not require manual CLAUDE.md edits

**Negative:**

- Agent must read `.sdd/agent-instructions.md` at session bootstrap (one additional read)
- Agents that skip `.sdd/agent-instructions.md` operate with incomplete context

## Alternatives Rejected

**Snapshot:** Governance content duplicated in `CLAUDE.md`. Diverges silently on
`sdd governance compile` unless CLAUDE.md is manually updated every time. Rejected
because the divergence risk outweighs the convenience of having rules in one file.

**Hybrid (partial content + pointer):** Some rules inline, others delegated. Creates
ambiguous precedence — which rules take priority? Rejected because the complexity
provides no benefit over pure pointer.

## Implementation Notes

- Current `CLAUDE.md` already implements this decision (see `CLAUDE.md` at workspace root)
- This ADR documents the existing state retroactively to prevent accidental reversal
- The precedence rule is enforced by the statement: "If that file says something different
  from what you remember seeing in CLAUDE.md, trust `.sdd/agent-instructions.md`"
