# 💬 RULESET — Comments

## 🎯 Purpose

Preserve intent and historical context.

---

## 🔒 HARD RULES

- Existing comments MUST NOT be removed

- Public functions MUST include docstrings:
  - intent
  - usage example

---

## 🟡 SOFT RULES

- Comments SHOULD explain WHY, not WHAT

---

## 🧬 TRACEABILITY

Comments SHOULD reference:

- issue IDs
- commit SHAs
- upstream constraints

---

## ❌ ANTI-PATTERNS

- redundant comments
- removing legacy context
